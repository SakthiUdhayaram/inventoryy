Inventory - Simple Flask Inventory App
----------------------------------------
How to run:
  1. Create a venv (recommended): python -m venv venv && source venv/bin/activate
  2. Install dependencies: pip install flask sqlalchemy flask_sqlalchemy
  3. From project root run: python app.py
  4. Open http://127.0.0.1:5000 in your browser

Notes:
- This is a demo. For production, change SECRET_KEY, use a proper DB and WSGI server.
